# Changelog

## [2.0.0](https://github.com/Wixonic/WixiBot/compare/v1.0.0...v2.0.0) (2026-11-11)


### Major Features

* **Onion Storage**
* **RichPicture:** Aims to make Applications' answer consistent by answering with images (rich pictures) containing lots of data when useful
* **Activity:** Added a welcome message feature for new guild members.
* **Activity:** Introduced a new `/profile` command to display user stats and achievements, along with `/leaderboard` to display top active members.
* **Settings:** Dynamic settings for users and guilds, with a simple and feature-rich interface.
* **Privacy:** Add RGPD-compliant options to request and delete stored data.
* **Moderation:** Basic manual moderation system.
* **Birthday:** Add birthday system.
* **Funding:** Command and logic to allow exclusive access to some parts of your server for your supporters
